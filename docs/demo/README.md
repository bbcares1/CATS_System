# Demo claim documents

These PDFs are fictitious classroom samples for **Sam Staff / S001**, **Demo - Cloud deployment basics**, **9 October 2026**, **SGD 200**.

1. Log in as `staff`, open the Approved course in Course history, enter experience comments and click **Mark completed**.
2. Open **Fee claims**, select that completed course and confirm that the fee was paid personally.
3. Upload [the receipt](sam-cloud-receipt.pdf) as the receipt and [the certificate](sam-cloud-certificate.pdf) as the certificate, then submit.

The seeded pending, paid and approved/unpaid claims already have their own matching sample documents. The initial Approved course has no claim so you can demonstrate submission. Run the demo reset before repeating the flow.
